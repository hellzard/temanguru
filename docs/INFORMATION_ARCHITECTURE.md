## Responsive rules

- 320–767: single column, bottom navigation, full-screen task flows.
- 768–1099: navigation rail, two-column where appropriate.
- 1100+: sidebar, content, optional context panel.
- Table-heavy pages must provide mobile card/list mode and column chooser.

## Global interactions

- Command palette `Ctrl/Cmd + K`.
- Notification center.
- Sync status always visible when offline data exists.
- Breadcrumb on desktop for nested document/workflow pages.
- Contextual bulk action bar after selection.

## Visual direction

Calm Education Productivity:
- clean, warm, professional, not childish
- restrained motion
- meaningful status colors
- generous touch targets
- no excessive glassmorphism or low-contrast text
