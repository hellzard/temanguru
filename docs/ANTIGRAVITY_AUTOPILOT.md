# Antigravity Autopilot untuk Pemula

Antigravity akan memperbaiki source, menginstal dependency, menjalankan Docker/Supabase lokal, menguji migration/RLS, melakukan browser QA, menghubungkan GitHub/Supabase/Vercel, membuat Preview, dan mendeploy production setelah aman.

## Langkah pengguna

1. Ekstrak ZIP.
2. Buka Antigravity → New Project → Add Folder.
3. Pilih folder `temanguru`.
4. Buka Agent, pilih Local Mode.
5. Jalankan `/temanguru-autopilot`.
6. Selesaikan login GitHub/Supabase/Vercel bila browser memintanya.
7. Jangan mengirim password, OTP, atau key ke Agent.
8. Setujui production hanya setelah quality gate hijau.

## Tanda selesai

Workspace tanpa login, backup/restore, email+sandi, OTP, sync dua perangkat, RLS akun A/B, lint/typecheck/unit/build/audit/pgTAP/Playwright, GitHub Actions, Preview, production, health SHA, dan rollback semuanya terbukti.
