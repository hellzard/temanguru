# UX Flows

## First run

Login → create school workspace → academic year → add class → import/add students → add subject and schedule → arrive at Today dashboard.

## Daily attendance

Today → tap current class → “Mulai Presensi” → all present by default → change exceptions → add optional note → save → offer journal continuation.

## Daily journal

From attendance or Today → pre-filled date/class/subject/duration → enter topic and activity → optional reflection/obstacle/follow-up → save draft/finalize → monthly recap updated.

## Score entry

Class → assessment → choose/create assessment → score grid/card list → detect missing values → save → show remedial candidates without finalizing automatically.

## Remedial

Assessment → candidate list → schedule/record attempt → preserve original score → teacher selects policy/result → audit history remains visible.

## Export

Reports → choose class/period/report type → preview filters and missing data → generate CSV/print/PDF → download with sanitized filename.

## Offline

Connection lost → banner → form continues as local draft → save to outbox → reconnection → explicit sync → conflict screen if server data changed.

## Error recovery

Errors state what happened, what data is safe, and one next action. Never clear a form because a request failed.
