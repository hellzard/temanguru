# Backup Manual Mode Tanpa Login

1. Buka `/workspace`.
2. Pilih **Backup & Sinkron**.
3. Klik **Unduh backup**.
4. Simpan file `.json` di lokasi aman.

Untuk memulihkan:

1. Buka menu yang sama.
2. Klik **Pulihkan backup**.
3. Pilih file JSON Teman Guru.
4. Baca nama workspace yang akan dipulihkan.
5. Konfirmasi penggantian data lokal.

Backup berisi data yang dimasukkan pengguna dan tidak terenkripsi dengan kata sandi. Jangan membagikan file melalui kanal publik.
