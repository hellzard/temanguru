# Accessibility Audit

- Confirm one H1 per page and logical heading order.
- Every field has a visible label and error association.
- All actions work with keyboard; focus is visible and not trapped.
- Icon-only buttons have accessible names.
- Color is never the only signal.
- Dialogs restore focus; menus support Escape.
- Tables have captions/headers or mobile card equivalents.
- Respect reduced motion and text zoom.
- Test at 200% zoom and 320 px width.
