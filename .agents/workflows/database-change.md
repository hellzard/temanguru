# Database Change

Description: Create safe Supabase schema and RLS changes.

5. Test anonymous, member, non-member, teacher, and admin cases.
6. Add backward compatibility and rollback notes.
7. Regenerate database types.
8. Ask security-reviewer to inspect SQL and policies.
