# UI Browser Review

Description: Verify Teman Guru visually and interactively before completion.

1. Start the app with the correct local environment.
2. Test 320×568, 390×844, 768×1024, and 1440×900.
3. Check keyboard navigation, visible focus, labels, dialogs, menus, tables, and forms.
4. Check reduced motion, zoom/reflow, long Indonesian text, and no horizontal overflow.
5. Check loading, empty, error, offline, and permission-denied states.
6. Validate touch targets and non-drag alternatives.
7. Capture screenshots/artifacts and list issues by severity.
8. Fix high and medium issues, then retest.
