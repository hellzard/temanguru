# Build Feature

Description: Implement one Teman Guru vertical slice with real persistence, authorization, UI states, tests, and browser evidence.

1. Select the active slice from status/tasks.
2. Read relevant specifications and skills.
3. Ask product-manager for acceptance criteria and security-reviewer for threat cases.
4. Write a file-level and migration-level plan.
5. Implement data boundary and authorization first.
6. Implement responsive UI with loading, empty, error, and success states.
7. Add tests including a negative authorization case.
8. Run the project quality gate.
9. Call `/ui-browser-review`.
10. Ask security and QA agents to review the final diff.
11. Fix findings.
12. Update status, decisions, and tasks; then commit coherently.
