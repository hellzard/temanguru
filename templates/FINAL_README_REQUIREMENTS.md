# Final README Requirements

The implemented repository README must include:

- product purpose and scope;
- screenshots only after UI exists;
- prerequisites;
- local setup;
- environment variable names;
- Supabase migration instructions;
- test/build commands;
- offline/PWA limitations;
- privacy notes;
- GitHub/Vercel deployment steps;
- production URL;
- current implementation status;
- no false official affiliation.
