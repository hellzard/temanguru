# Starter Code Scope

This workspace now includes a deliberately small, runnable foundation.

## Already included

- Next.js 16 App Router and TypeScript strict;
- Tailwind CSS;
- accessible landing page and responsive dashboard shell;
- Supabase SSR browser/server clients;
- `proxy.ts` session refresh and optimistic route protection;
- magic-link login and Auth callback;
- real school onboarding through `create_school_with_owner`;
- initial tenant-aware schema and RLS policies;
- `/api/health`;
- PWA manifest, conservative service worker, and offline page;
- CSV utility and local IndexedDB starter;
- Vitest, Playwright, ESLint, CI, secret scan, and release preflight;
- Antigravity rules, skills, agents, workflows, and product specifications.

## Intentionally not complete

- real class, student, schedule, attendance, journal, grade, and document CRUD;
- school member invitations and complete role management;
- generated Supabase TypeScript types;
- robust offline conflict resolution;
- PDF/DOCX visual editor;
- workflow/event/inventory modules;
- production telemetry, backups, rate limiting, and abuse prevention;
- AI features.

Antigravity must extend the starter through verified vertical slices. Placeholder pages are scaffolding, not completed features.
